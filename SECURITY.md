# Security Policy

## Supported Versions

Only the latest release is supported with security updates.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

- Use GitHub's [private vulnerability reporting](https://github.com/real21c/cloudflare-admin-toolkit/security/advisories/new), or
- Email **real21c@gmail.com**

You should receive a response within a few days. Please include steps to
reproduce and the version you tested (shown in the Settings screen).
